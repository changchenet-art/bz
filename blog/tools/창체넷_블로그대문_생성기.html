블로그 대문 생성기

㈜창체넷 · 홈페이지형 네이버 블로그

1. 테마

창체넷 브랜드 규정에 따라 배경·면에만 테마색을 쓰고 글자는 검정·회색으로 처리합니다.

2. 상단 타이틀

배경 이미지를 넣으면 글자는 흰색으로 자동 전환됩니다.

3. 크기

네이버 위젯은 폭 170px가 기본값입니다. 보유하신 「위젯등록방법 PDF」의 값이 다르면 그 값을 넣으세요.

4. 메뉴 위젯

이미지 주소는 네이버에 이미지를 올린 뒤 채우면 됩니다. 비워 두면 코드에 자리표시자가 들어갑니다.

5. 내보내기

설정은 이 브라우저에만 저장됩니다(이미지 파일은 제외).

상단 타이틀

블로그 관리 → 꾸미기 설정 → 타이틀에 등록합니다.

메뉴 위젯

각 조각을 위젯 1개로 등록합니다. 조각마다 링크가 따로 걸립니다.

위젯 등록 코드

아래 코드를 위젯직접등록 창에 하나씩 붙여넣습니다.

네이버 블로그에 올리는 순서
  1. 이미지 저장 — 위에서 「타이틀 PNG 저장」과 「위젯 PNG 전체 저장」을 눌러 이미지를 모두 받습니다.
  2. 타이틀 등록 — 관리 → 꾸미기 설정 → 스킨 선택·디자인 설정에서 타이틀 영역에 타이틀 이미지를 올립니다.
  3. 위젯 이미지 주소 확보 — 위젯 PNG들을 비공개 글에 첨부해 발행한 뒤, 각 이미지에서 마우스 오른쪽 → 이미지 주소 복사. 외부 호스팅은 나중에 끊길 수 있어 이 방법이 안전합니다.
  4. 주소 입력 — 왼쪽 각 메뉴의 「이미지 주소」 칸에 붙여넣으면 아래 코드가 자동으로 완성됩니다.
  5. 위젯 등록 — 관리 → 꾸미기 설정 → 디자인 설정 → 레이아웃·위젯 설정 → 위젯직접등록. 메뉴 개수만큼 위젯을 만들고 코드를 각각 붙여넣습니다.
  6. 배치 — 레이아웃 화면에서 위젯을 원하는 순서로 끌어다 놓고 저장합니다.
보유하신 「PPT 사용설명서」·「위젯등록방법 PDF」에 스킨별 세부 설정(레이아웃 폭, 여백 제거 등)이 더 자세히 나와 있습니다. 값이 다르면 그 문서를 우선하세요.
