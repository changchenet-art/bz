# 경리회계 업무지원실 · 통합 관리 시스템

스타트업 경리회계 업무지원실의 반복 업무를 한 곳에서 처리하는 **설치 불필요 웹 프로그램**입니다.
`index.html` 파일 하나로 동작하며, 데이터는 사용하는 브라우저에 자동 저장됩니다.

## 실행 방법

1. `index.html` 파일을 더블클릭하면 웹브라우저(크롬·엣지 권장)에서 바로 열립니다.
2. 별도 설치·서버·인터넷 연결이 필요 없습니다.
3. 입력한 데이터는 자동으로 저장됩니다(브라우저 localStorage).

> 여러 명이 함께 쓰거나 여러 PC에서 같은 데이터를 봐야 하면, 사내 공용 폴더·웹서버에 올려두거나
> `전체 백업(JSON)`으로 파일을 주고받아 `백업 복원`으로 불러오세요. (2단계에서 공용 DB 서버 연동 확장 가능)

## 주요 기능

| 메뉴 | 내용 |
|------|------|
| **대시보드** | 오늘·지연 할 일, 45일 이내 인증·계약 만료 알림, 이번달 수지·예산 집행률 요약 |
| **할 일 · 업무진도** | 매일 할 일 체크, 담당·마감·우선순위·진도(%), 오늘/이번주/지연 필터 |
| **거래처** | 발주·견적 대상 거래처 정보 관리 |
| **발주 · 견적** | 견적/발주 진행 현황, 금액·납기 관리 |
| **계약 관리** | 계약 체결·집행 현황, 착수계 제출 여부, 예산 연결 |
| **문서 생성** | 견적서·거래명세서·지출결의서·착수계·공문 작성 → 인쇄 / PDF 저장 |
| **거래내역 · 전표** | 통장/카드 내역, 세금계산서·영수증 증빙, 부가세 10% 자동, 계정별 집계, CSV 가져오기 |
| **사업예산 집행** | 사업별 예산 대비 집행 현황(거래내역 자동 연동) |
| **문서 · 인증 갱신** | 인증서·자격·보험 만료/갱신일 D-day 알림 |
| **연락처** | 강사·위촉자문·주요 연락처, 자문료 지급 계좌 |
| **직원 명부 / 휴가·근태** | 직원 정보, 연차 부여·사용·잔여 자동 계산, 휴가 신청 관리 |

## 데이터 가져오기 / 내보내기

- **CSV 가져오기**(거래내역): 은행·카드사에서 다운로드한 엑셀/CSV를 그대로 불러옵니다.
  `일자/날짜/거래일`, `적요/내용/가맹점`, `출금/입금/금액` 등 흔한 컬럼명을 자동 인식합니다.
- **CSV 내보내기**: 각 목록을 엑셀에서 열 수 있는 CSV로 저장(한글 깨짐 방지 BOM 포함).
- **전체 백업(JSON)**: 모든 데이터를 파일 하나로 백업/복원. **주기적으로 백업하세요.**

## 주의사항

- 데이터는 해당 브라우저에만 저장됩니다. 브라우저 데이터 삭제 시 함께 지워지므로 **정기 백업** 권장.
- 세금·급여 계산은 참고용 보조 기능입니다. 신고·지급 전 반드시 담당 세무사·규정을 확인하세요.

## 확장 로드맵 (2단계)

- PDF·이미지 영수증 OCR 자동 입력 (파이썬 스크립트 연동)
- 더존·세무사랑 등 회계프로그램 내보내기 포맷 지원
- 급여·4대보험 상세 계산 및 급여명세서 발급
- 공용 데이터베이스 서버 연동(다중 사용자·다중 PC)
