11차시
  • 검은머리물떼새를 비롯한 갯벌 생물의 생태적 특징을 설명하고, 먹이 관계로 갯벌 생태계의 연결성을 이해합니다.
  • 갯벌 서식지 감소가 생물다양성에 미치는 영향을 먹이사슬 관점에서 추론합니다.

4검은머리물떼새의 편지
🖼 00_검은머리물떼새_갯벌.png
"안녕, 친구들! 나는 서해안 갯벌에 살고 있는 검은머리물떼새라고 해. 까만 양복에 하얀 셔츠를 입은 것처럼 멋지지? 주황빛 붉은 눈과 부리 덕분에 갯벌의 멋쟁이 신사라는 별명도 있어. 내가 왜 이 진흙투성이 갯벌에 사냐고? 이곳이 내게는 세상에서 가장 맛있는 먹이가 가득한 '보물창고'이기 때문이야! 그런데 요즘 갯벌이 조금씩 사라지고 있어서 마음이 아파. 갯벌이 아프면 조개와 게가 사라지고, 결국 나 같은 새들도 살 수 없게 되거든."
발문  검은머리물떼새가 갯벌을 '보물창고'라고 부른 이유는 무엇이었을까요?

8갯벌 생물 퀴즈 ① 맞으면 O, 틀리면 X
  • 이 식물은 가을이 되면 갯벌을 붉은 양단처럼 물들여요. 한 해 7가지 색으로 변해서 이름 붙여진 이 식물은 '갈대'입니다.  ( O  ,  X )
  • '파래'는 바위나 진흙에 붙어 자라는 초록색 해조류입니다. 갯고둥이나 초식 동물의 식사가 됩니다.  ( O  ,  X )
  • '동죽'은 대나무 마디처럼 길쭉한 조개로, 위험을 감지하면 구멍 깊숙이 도망칩니다.  ( O  ,  X )
  • '밤게'는 앞으로 똑바로 걸어 다니며 죽은 생물의 사체를 먹는 '갯벌의 청소부'입니다.  ( O  ,  X )
  • '농게'는 수컷의 몸집만 한 거대한 붉은 집게발 하나가 특징입니다.  ( O  ,  X )
  • '짱뚱어'는 피부로도 숨을 쉴 수 있어 물 밖 갯벌 위를 뛰어다닙니다.  ( O  ,  X )
  • '저어새'는 고양이 울음소리를 내며, 물고기·게·사체를 가리지 않고 먹는 새입니다.  ( O  ,  X )
진행 개인 화이트보드에 O/X를 써서 동시에 들기  ·  정답 1.X(칠면초) 2.O 3.X(맛조개) 4.O 5.O 6.O 7.X(괭이갈매기)

2단계 — 화살표로 잇기
화살표는 항상 먹히는 쪽 ➔ 먹는 쪽을 향하게.
  • 파래 ➔ 바지락 ➔ 민꽃게 ➔ 검은머리물떼새

  • 칠게·농게 ➔ 낙지 ➔ 괭이갈매기

  • 더 이상 먹이를 구하지 못해 굶주리게 됩니다.
  • 아기 새들을 건강하게 키울 수 없습니다.
  • 숫자가 점점 줄어 결국 멸종 위기에 처하게 됩니다.

갯벌은 스펀지이다.
태풍의 파도 에너지를 흡수해 마을 침수를 막아주기 때문이다.
갯벌은 정수기이다.
생활하수와 오염물질을 미생물과 조개들이 깨끗하게 걸러주기 때문이다.
갯벌은 보물섬이다.
수많은 바다 생물이 살며 어민들에게 풍요로운 삶을 선물하기 때문이다.
갯벌은 휴게소이다.
멀리 이동하는 지친 철새들이 쉬어가고 배불리 먹을 수 있는 장소이기 때문이다.
갯벌은 지구의 에어컨이다.
