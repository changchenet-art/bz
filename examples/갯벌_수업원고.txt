8 — 갯벌 생물 퀴즈 ① 맞으면 O, 틀리면 X
이 식물은 가을이 되면 갯벌을 붉은 양단처럼 물들여요. 한 해 7가지 색으로 변해서 이름 붙여진 이 식물은 **'갈대'**입니다. ( O , X )
**'파래'**는 바위나 진흙에 붙어 자라는 초록색 해조류입니다. 갯고둥이나 초식 동물의 식사가 됩니다. ( O , X )
**'동죽'**은 대나무 마디처럼 길쭉한 조개로, 위험을 감지하면 구멍 깊숙이 도망칩니다. ( O , X )
**'밤게'**는 앞으로 똑바로 걸어 다니며 죽은 생물의 사체를 먹는 '갯벌의 청소부'입니다. ( O , X )
**'농게'**는 수컷의 몸집만 한 거대한 붉은 집게발 하나가 특징입니다. ( O , X )
**'짱뚱어'**는 피부로도 숨을 쉴 수 있어 물 밖 갯벌 위를 뛰어다닙니다. ( O , X )
**'저어새'**는 고양이 울음소리를 내며, 물고기·게·사체를 가리지 않고 먹는 새입니다. ( O , X )

19 — 정리 · 갯벌은 ○○이다

화이트보드에 나만의 문장을 완성해 봅시다. 　갯벌은 (　　　　)이다. 왜냐하면 　　　　　　　　　　 때문이다.

예시

갯벌은 스펀지이다. 태풍의 파도 에너지를 흡수해 마을 침수를 막아주기 때문이다.
갯벌은 정수기이다. 생활하수와 오염물질을 미생물과 조개들이 깨끗하게 걸러주기 때문이다.
갯벌은 보물섬이다. 수많은 바다 생물이 살며 어민들에게 풍요로운 삶을 선물하기 때문이다.
갯벌은 휴게소이다. 멀리 이동하는 지친 철새들이 쉬어가고 배불리 먹을 수 있는 유일한 장소이기 때문이다.
갯벌은 지구의 에어컨이다. 이산화탄소를 많이 흡수해 지구 온도가 오르지 않도록 도와주기 때문이다.
