# 갯벌 수업 PPT — 자료 폴더

이 폴더에 원고가 참조하는 이미지를 넣어두면, 생성기가 **파일명을 맞춰 자동으로**
슬라이드 자리표 위치에 끼워 넣습니다(없으면 점선 자리표로 남습니다).

## 넣는 위치
- 일반 이미지 → `images/`
  - 예: `00_검은머리물떼새_갯벌.png`, `01_검은머리물떼새_실사.png`,
        `10_우리나라주요갯벌_지도.png`, `11_가치.png` … `16_가치.png`,
        `17_역할극_다양한주체.png`
- 생물카드 21종 → `images/생물카드/`
  - 파일명은 생물 이름과 매칭됩니다. 예: `갈대.png`, `바지락.png`, `검은머리물떼새.png` …
  - (앞에 번호가 붙어도 됩니다: `01_갈대.png` 처럼 — 이름이 포함되면 매칭)

## 생성
    python3 scripts/build_gaetbeol.py                 # 기본 폴더(assets/갯벌_수업) 사용
    python3 scripts/build_gaetbeol.py <다른폴더경로>   # 폴더 직접 지정
